# Unterlagen

Ablage für alles, was die Anlage und das Gebäude beschreibt. Dateien einfach in
den passenden Unterordner legen — PDF, DWG, Foto, Screenshot, Export, egal.
Bitte mit sprechendem Dateinamen und Datum, z. B.
`2026-08-28_grundriss-num2.pdf`.

## Ordner

| Ordner | Inhalt |
|---|---|
| `plaene/` | Grundrisse, Schnitte, Paneelaufbau, Kältetechnik-Schema, Rohrleitungsplan |
| `steuerung/` | Reglertyp, Parameterlisten, Regelstrategie, Screenshots der Bedienoberfläche, Schaltpläne |
| `fotos/` | Fotos vom Befund, mit Datum und Standort |

## Hinweis zur Ablage

Sensible Daten — Passwörter, Fernzugangs-Zugangsdaten, Lizenzschlüssel der
Steuerung — gehören **nicht** in dieses Repository. Wenn eine Unterlage solche
Angaben enthält, vorher schwärzen oder die Stelle nur beschreiben.
